# mylesnorton.com

Personal site for Myles Norton, accounting student and future CPA in public tax.

Static site: `index.html` plus assets. No build step. Deployed on Vercel; domain registered at Porkbun.

- `index.html` – the site
- `Myles_Norton_Resume.pdf` – linked from the Résumé buttons
- `og.png` – link preview image
- `robots.txt`, `sitemap.xml` – for search engines

To update the site, edit `index.html` and push to `main`. Vercel redeploys automatically.
